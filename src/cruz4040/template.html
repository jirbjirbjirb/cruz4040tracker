Did Oneil Cruz have a shot at 40/40?

This project started life as a python terminal script that was intended to post automatically to a bluesky account each day of the regular season, updating subscribers on Oneil Cruz's current projected homer and stolen base totals. It has been reworked into a retrospective data visualization exercise showing how those chances rose and fell throughout the year.
